# Student Performance Prediction System

## Project Overview

The Student Performance Prediction System is a
Machine Learning project that predicts students'
Mathematics scores using academic and lifestyle data.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Gradio
- Google Colab
- Visual Studio Code

## Dataset Features

- Study Hours
- Attendance
- Previous Score
- Sleep Hours
- Math Score

## Machine Learning Algorithm

Linear Regression

## Model Evaluation

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R2 Score

## Application

An interactive Gradio application allows users
to enter student details and receive a predicted
Mathematics score.
